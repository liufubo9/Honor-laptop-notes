## 以后怎么同步

1. 把要上传的 .md 文件放到 **D 盘根目录**，或者直接放进本文件夹
2. 双击 **同步到GitHub.bat**
3. 窗口里出现 **Done** 就成功了

脚本运行时显示的是英文提示，属正常。
它会自动收集 D 盘根目录的所有 .md，提交并推送。
